# WinterHaus Holiday Market

## About the Website

WinterHaus Holiday Market is a website that gives visitors information about a holiday market. It helps people find event details, check the schedule, explore vendors, learn about parking, read FAQs, and sign up for updates.

This website was created for my web development capstone project. I focused on making it responsive, accessible, easy to navigate, and organized so the code is easier to maintain.

**Live Website:** https://amelsea.github.io/Capstone-website/

**GitHub Repository:** https://github.com/amelsea/Capstone-website

## What's Included

- **Event information:** Basic details about the holiday market.
- **Schedule:** Information about the event schedule and activities.
- **Vendors:** Images and information about market vendors.
- **Parking and market map:** Helpful information for finding the event and getting around.
- **FAQs:** Answers to common questions visitors might have.
- **Newsletter signup:** A form for visitors who want updates.
- **Navigation:** Links that help visitors move between sections of the website.
- **Responsive design:** A layout that adjusts to different screen sizes.

## Tools and Technologies

I used the following to build the website:

- **HTML** for the page content and structure.
- **CSS** for colors, fonts, spacing, and layouts.
- **CSS custom properties** to keep design choices consistent.
- **CSS Grid and Flexbox** to organize content.
- **Media queries and container queries** to help the layout adjust to different screen sizes.
- **GitHub Pages** to publish the website.
- **HTML metadata and JSON-LD** to help with search results and social media sharing.

## Design and Accessibility

The website uses a holiday-inspired design with warm backgrounds, red and green accents, and readable fonts.

I also considered accessibility by using semantic HTML, keyboard-friendly navigation, visible focus styles, and alternative text for informative images. The layout is designed to work on smaller and larger screens, including when users zoom in.

The CSS is organized into separate layers for things like basic styles, layouts, components, utilities, responsive changes, and print styles. This makes it easier to find and update styles without changing unrelated parts of the website.

## Project Files

- `index.html` — Contains the main website content.
- Main CSS file — Controls the website's appearance and layout.

## Testing

The website was tested for:

- How it looks on narrow, medium, and wide screens.
- Whether the content still works at 200% browser zoom.
- Whether the navigation and links work.
- Whether keyboard users can move through the page and see the focus indicator.
- Whether images have appropriate alternative text.
- Whether forms and buttons are usable and aligned correctly.
- Whether the HTML and CSS have errors.
- Whether the page title, description, social sharing metadata, and structured data are correct.
- Whether the published website displays the latest changes.
